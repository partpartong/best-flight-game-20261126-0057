Ridge Runner — a mountain-valley flight game. Fly a prop plane down a green valley between a lake and snow-capped peaks, thread 8 glowing rings, then land on the runway. Chase view or cockpit view with lit instruments (altitude, airspeed, heading, artificial horizon, throttle), keyboard + mouse controls, synthesized engine and wind sound, and a score for rings and landings. Throttle back to sink, throttle up to climb; slow flight stalls below 48 kt. Pure Canvas 2D, no libraries, no network, no external assets — the whole game is static files under `game/`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

To play it, open `game/index.html` in a desktop browser (Chrome recommended). Fly with arrow keys / WASD, Shift/Ctrl for throttle, mouse to steer, C to switch cockpit/chase view, P to pause, R to restart.
